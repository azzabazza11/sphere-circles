# Sphere Circles

Animated tangential circles on a sphere — desktop playground + phone screensaver.

## Live

- Desktop: https://azzabazza11.github.io/sphere-circles/
- Screensaver: https://azzabazza11.github.io/sphere-circles/screensaver.html

## Local

```bash
python3 -m http.server 8080
```

Open http://localhost:8080/

## Features

- Up to **512** circles (detail auto-throttles at high counts)
- **Auto flow** — slowly morphs settings into new looks
- Fly mode along circle-plane normals
- Glow, ghost trails, twist, drift, hue drift, presets
